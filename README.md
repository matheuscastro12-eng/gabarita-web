# Gabarita

IDE agêntica de estudo para o ENEM: a questão de um lado, um tutor de IA do outro.

Foco inicial: matemática (probabilidade, funções, equação do 2º grau, regra de três, porcentagem, razão e proporção, estatística básica, leitura de gráficos).

O desenvolvimento acontece em branches com PR para `main`.
